# Ficha oficial de D&D 5e → atributos do Multicompêndio

144 atributos, gerados a partir do PDF *Ficha Oficial D&D 5E Editável* (3 páginas, 335 campos). Dos 144, **32 são calculados**: o valor não é digitado, sai de outros atributos (veja a seção *Atributos calculados*, no fim).

Os campos do PDF têm nomes genéricos ("Campo de Texto23"); a correspondência abaixo foi feita pela posição de cada campo na página.

Serve de base para a exportação em PDF (RF10).

**Fora do modelo, de propósito:**

- *Nome do Personagem* (todas as páginas): é o nome do próprio personagem.
- *História do Personagem* (pág. 2, Campo de Texto17): é a história de origem do personagem (RF08), comum a todos os sistemas.
- *Símbolo* (pág. 2, Image77): campo de imagem — ainda não há atributo do tipo imagem.
- *Preparada* (pág. 3, 93 caixas): cada linha de magia tem uma caixa; no modelo, as magias de cada círculo são um texto longo, no qual se anota o que está preparado.
